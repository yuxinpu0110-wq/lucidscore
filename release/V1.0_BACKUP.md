# v1.0 本地基线备份

当前产品版本为v1.0（工程版本号1.0.0）。这是开始v2.0开发前保存的本地基线，包含第二／第三行小节框滑动与明暗连续性修复、网页播放优化，以及供编辑的109条启发文本。

完整归档保存在项目根目录 `backups/v1.0-日期时间/`，目录内提供：

- `LucidScore-v1.0.0-windows-x64.zip`：自带运行环境的Windows便携版，完整解压后双击START.cmd，无需安装开发工具。
- `LucidScore-v1.0.0-source.zip`：当前工作区源码快照，包含录音原件、谱面、内容、构建及封装脚本，可用于恢复开发；安装Node.js 24、npm、FFmpeg后运行npm ci及npm run dev。
- `BACKUP.json`：归档时间、版本、验证记录、包体积与SHA-256；另附独立校验和文件。

源码快照来自当前工作区，包含尚未提交的修改，并非只备份此前Git提交。恢复时建议解压到新目录；原工作区继续用于后续开发。备份不含agent／context等工作记录、密钥、依赖缓存或临时隧道。

本次没有发布到GitHub，也没有重新制作Mac便携包；现有公开v0.1.0及Mac发行物保持原样。完整音频和谱面资源保留在Windows成品中，源码快照保留来源录音，首次运行会生成播放缓存。音乐分析及谱音映射仍保留原有待校核状态，产品版本号不表示内容审阅已经全部完成。
