# 移动端界面

移动端规则仅在视口宽度不超过768px时生效，集中在`src/mobile.css`。桌面继续使用原有双栏及播放器布局。

- 门厅：五个68px高的纵向乐章卡片；无横向卡片滚动条。品牌仅键盘focus-visible显示描边。
- 舞台：48px顶栏包含品牌、罗马数字导航和设置；44px次栏显示当前乐章及聆听模式。
- 设置：连续播放与录音选择随断点移入底部dialog，沿用原状态，保留Escape关闭与焦点返回；不创建重复输入。
- 播放：60px底部玻璃胶囊，圆形播放／暂停按钮、时间、进度及±5秒；保留按钮原有可访问名称与独立音频引擎。
- 谱面：32px工具条，下方约30dvh、上限240px；内容宽180%，支持触摸双向平移。按小节变化计算SVG投影，将定位框横向居中，减少动态时直接定位。触摸时暂缓自动跟随。
- 导读：紧接谱面，标题1.3rem、正文0.95rem／1.75，底部留88px；返回出发位置改为紧凑提示条。谱面栏sticky，阅读时仍可观察谱面。

运行`npm run test:mobile`，检查320／390／768px的纵向卡片、设置抽屉、固定播放舱、同屏导读和横向跟随，并检查1440px桌面双栏。截图在本地`tmp/mobile/`。另通过生产播放与音频引擎检查，确认五章播放、连续播放、单音源与HLS均正常。

这些是桌面Edge的视口模拟验收，尚未进行真实iPhone／Android触摸及安全区实机测试。可在同一Wi-Fi下运行`npm run dev -- --host 0.0.0.0`，用手机访问终端的Network地址继续验证。
